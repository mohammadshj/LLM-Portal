# نتیجهٔ بررسی نسخهٔ اولیه

این بررسی روی محیط فعلی انجام شده است؛ اتصال تجاری LLM یا سرور عمومی اعتبارسنجی نشده است.

- ساخت imageهای Backend و Frontend با حفظ TLS verification موفق بود.
- migrationهای Django روی PostgreSQL 17 اجرا شدند؛ `makemigrations --check --dry-run` تغییری گزارش نکرد.
- ۱۲ آزمون Backend روی PostgreSQL اجرا و همگی موفق شدند؛ شامل ورود/خروج با CSRF، الزام احراز هویت، جداسازی کاربران، کنترل سهمیه و context، مقایسه با تاریخچهٔ مستقل، خطای جزئی provider، پاک‌سازی و حفظ آمار، مجوز گزارش مدیر و رقابت دو درخواست هم‌زمان برای یک سهمیه.
- `npm run build` شامل TypeScript strict check و Vite build موفق بود.
- `ruff check backend` موفق بود.
- تنظیم Nginx با `nginx -t` بررسی شد. درخواست `/api/health/` از مسیر Nginx به Django و PostgreSQL پاسخ موفق داد.
- آزمون Playwright با Chromium نصب‌شدهٔ محیط انجام شد: ورود کاربر آزمایشی، مقایسهٔ دو مدل نمایشی، ماندگاری تاریخچه پس از reload، گزارش مدیر، تاریخچه در موبایل، حذف گفتگو و خروج موفق بود. در عرض ۳۹۰ پیکسل سرریز افقی و خطای JavaScript ثبت نشد.

برای تکرار آزمون Backend:

```sh
docker compose run --rm backend python manage.py test portal --verbosity 2
```

هر دو مدل این آزمون مرورگر نمایشی بودند. آداپتور واقعی به کلید معتبر، دسترسی شبکه و مدل سازگار نیاز دارد. مصرف نمایشی معیار دقت tokenizer مدل واقعی نیست. بررسی تصویری دسکتاپ و موبایل انجام شد؛ آزمون دسترس‌پذیری جامع و آزمون بار انجام نشده‌اند.

## فونت وزیرمتن و حالت تیره

- ساخت Frontend و بررسی TypeScript موفق بود؛ وابستگی جدیدی اضافه نشد.
- محتوای هر ۱۰ فونت ارسالی در پروژه نگه داشته شد؛ نسخهٔ Variable با نام فایل `Vazirmatn-Variable.woff2` استفاده می‌شود. فایل مجوز OFL از مخزن رسمی فونت همراه فایل‌ها قرار گرفت.
- Playwright روی فایل‌های خروجی production با همان CSP پیکربندی Nginx اجرا شد. مسیرهای API در این بررسی رابط کاربری شبیه‌سازی شدند؛ این بررسی، آزمون تازهٔ Backend یا اتصال LLM واقعی نیست.
- Chromium با اطلاعات فونت رندرشده تأیید کرد که عنوان فارسی از فونت سفارشی Vazirmatn استفاده می‌کند؛ تنها یک درخواست فونت برای نسخهٔ Variable ثبت شد.
- پیروی اولیه و زنده از تم سیستم، تغییر دستی، حفظ انتخاب بعد از reload، همگام‌سازی تب‌ها و کارکرد در صورت مسدودبودن localStorage موفق بود.
- اعمال تم قبل از اجرای React با متوقف‌کردن دریافت bundle برنامه بررسی شد؛ فایل راه‌انداز تم با CSP اجرا شد.
- صفحهٔ ورود، گفتگو و گزارش در دو تم بررسی شدند. در عرض‌های ۱۴۴۰، ۷۶۸، ۳۹۰ و ۳۲۰ پیکسل سرریز افقی ثبت نشد. تصاویر دسکتاپ و موبایل حالت تیره نیز بازبینی شدند.
